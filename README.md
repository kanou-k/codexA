# 菜園ノート

家庭菜園の作物・作業記録・予定・収穫量を管理するウェブアプリです。

## 使い方

`index.html` をブラウザで開くだけで動きます（ビルド・サーバー不要）。

スマホでは、公開した URL（下の「アプリを公開する」）を開いて「ホーム画面に追加」すると、アプリとして入れられます。一度開けばオフラインでも使えます。

- iPhone：Safari の共有ボタン →「ホーム画面に追加」
- Android：Chrome のメニュー →「アプリをインストール」または「ホーム画面に追加」

- **ホーム**：今日やること、今月が植えどきの野菜
- **畑**：畑のマスやプランターをタップして、植えた作物を記録。プランターは畑の外（上下左右）に置ける
- **作物**：植え付け日・場所・収穫の目安日を登録、ワンタップで水やり記録
- **記録**：水やり・追肥・収穫などの作業履歴
- **予定**：期日つきのやることリスト
- **収穫**：今年の収穫量の集計、データの書き出し・読み込み

データは各端末のブラウザ内（localStorage）に保存されます。「端末間の共有」を設定すると、複数の端末で同じデータを使えます。バックアップは「収穫」画面の書き出しを使ってください。

植えどきと収穫までの日数は中間地の一般的な目安です。`logic.js` の `PRESETS` で変更できます。

## 端末間の共有

スマホとパソコン、家族の端末などで同じデータを使うための設定です。データの置き場所に Firebase Realtime Database（無料枠）を、アプリの公開に GitHub Pages を使います。

### 1. アプリを公開する（GitHub Pages）

1. GitHub のリポジトリで **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」にし、アプリが入っているブランチと `/ (root)` を選んで保存する
3. 数分後に表示される URL（`https://ユーザー名.github.io/リポジトリ名/`）を各端末で開く

非公開リポジトリで Pages を使うには GitHub の有料プランが必要です。

### 2. データの置き場所を作る（Firebase）

1. <https://console.firebase.google.com/> で Google アカウントにログインし、プロジェクトを 1 つ作る（アナリティクスは不要）
2. 左メニューの **構築 → Realtime Database** で「データベースを作成」を選ぶ（ロックモードのままでよい）
3. **ルール** タブの内容を次のものに置き換えて「公開」する

   ```json
   {
     "rules": {
       "gardens": {
         "$code": {
           ".read": "$code.length >= 16",
           ".write": "$code.length >= 16"
         }
       }
     }
   }
   ```

4. **データ** タブの上部に出ている URL（`https://〇〇-default-rtdb.firebaseio.com` など）を控える

### 3. アプリで設定する

1. 1 台目：**収穫 → 端末間の共有 → 共有を設定する** に上の URL を貼って保存する（合言葉は自動で作られる）
2. 「共有リンクをコピー」でリンクを取り、2 台目以降はそのリンクを開く

### しくみと注意

- 合言葉を知っている端末だけがデータを読み書きできます。ログイン機能はないので、共有リンク（合言葉を含む）は共有したい相手だけに渡してください。
- 同期は、変更の約 1 秒後・アプリを開いたとき・開いている間の 30 秒ごとに行います。
- オフラインでも使え、つながったときに同期します。別々の端末で編集した内容は、作物・記録・予定などの 1 件ごとに新しい方を採って合わせます。同じ 1 件を両方で編集した場合は、後から編集した方が残ります。
