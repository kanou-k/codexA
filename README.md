# 菜園ノート

家庭菜園の作物・作業記録・予定・収穫量を管理するウェブアプリです。

## 使い方

`index.html` をブラウザで開くだけで動きます（ビルド・サーバー不要）。

- **ホーム**：今日やること、今月が植えどきの野菜
- **作物**：植え付け日・場所・収穫の目安日を登録、ワンタップで水やり記録
- **記録**：水やり・追肥・収穫などの作業履歴
- **予定**：期日つきのやることリスト
- **収穫**：今年の収穫量の集計、データの書き出し・読み込み

データはブラウザ内（localStorage）に保存されます。バックアップは「収穫」画面の書き出しを使ってください。

植えどきと収穫までの日数は中間地の一般的な目安です。`logic.js` の `PRESETS` で変更できます。

## テスト

```
node --test
```
